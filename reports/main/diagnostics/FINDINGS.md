# Stopping events and performance gaps

The diagnostic pass covers all 153,600 criterion outcomes from the 15,360 completed trajectories. It distinguishes early triggers, triggers exactly at the budget, and non-triggering fallback. Fixed-budget baseline outcomes are a separate category. All outcomes remain in cost/performance averages.

The following descriptive subset uses uncertainty acquisition, linear SVM, 15% symmetric noise, and 30 seeds. A gap means selected macro F1 is more than .01 below the best observed point on the same finite trajectory.

## Interpretation

The zero fixed/easy contrasts on baseball/hockey and graphics/Windows arise from 30 fallbacks per rule, not successful early stopping. Nine baseball/hockey and eight graphics/Windows fallback outcomes fall below an earlier trajectory peak.

All 12 balanced-synthetic easy-set early stops exceed the retrospective gap threshold. On the imbalanced synthetic task, 13 of 15 easy-set early stops do so. These are conditional descriptive counts, not population guarantees. They support examining why the easy set stabilizes before broader performance stabilizes.

## Reproduction

```sh
python -m stoplab.diagnostics --runs reports/main/runs.csv --output reports/main/diagnostics
```

The command requires the original per-run table generated by `stoplab report`. Summary CSVs alone cannot reconstruct event-level pairing. `analysis.json` records the input hash. `failure-modes.csv` retains all tasks, learners, noise modes, query policies, and criteria. Rates use all seeds as their denominator except explicitly named conditional gap rates, which use only the corresponding event count and are blank when that count is zero. Pointwise bootstrap intervals resample seeds. Degenerate zero-event intervals do not establish zero population risk.

The peak reference is retrospective and changes with the labeling budget. A gap is not by itself evidence of an early stopping error. [Threshold sensitivity](SENSITIVITY.md) is analyzed separately. Representative-trajectory interpretation remains future work.
